# Подготовка раздачи LUMA

Сборка: Actions → Build Orbital LUMA multiplayer package.

При изменениях в release/ или ручном запуске GitHub собирает Windows-клиент из закреплённого исходного кода, проверяет архив Orbital 0.5.3 по SHA-256 и создаёт **черновик** Releases. Сборка может занять до двух часов.

В черновике будут ZIP, SHA256SUMS.txt и описание пакета orbital.json. Черновик не доступен другим игрокам. Он содержит согласованную пару клиента и оригинального Orbital Laser 0.5.3.

Сборка проверяет сетевые контракты. Перед публикацией отдельно проверяются два способа хостинга Horizon, доставка эффектов и звуковых событий, одинаковые изменения блоков у хоста и гостя и отказ при несовпадении включённых модов в обоих направлениях. Проверка проводится двумя процессами в отдельных тестовых мирах; два физических компьютера через VPN проверяются отдельно.

После успешной проверки добавляется квитанция publication/orbital-0.5.3-luma.1.json. Процесс Publish accepted Orbital package сверяет исходный коммит и SHA-256 архива, публикует пакет и обновляет catalog/orbital.json. Опубликованный пакет сохраняется неизменным; обновление требует нового тега и совместимого клиента.

В репозиторий и Releases не добавляются ресурсы Minecraft, серверные JAR, миры и личные настройки. Подготовленные ресурсы каждый игрок получает из своей установки Minecraft.
