Orbital Laser 0.5.3 with the LUMA native multiplayer bridge.

Install using the LUMA Mods tab. Every player needs the same enabled package. The host opens their world to LAN with guest commands enabled; friends join the host's VPN IPv4 address and the displayed port.

The bridge shares approved Orbital effects, sound events and host-authorized terrain edits. A different package version or enabled state is rejected before entering the world. One shared strike runs at a time. Enabling or disabling requires closing the game.

The original Orbital component and assets are included unchanged with their notices. Horizon sources are pinned to cbceb3f0e8dbd2eba25d3ba0c826338c93e35226; the LUMA patches are published in this repository. Minecraft resources, worlds and account data are not included.

This release remains a draft until two-client acceptance checks finish. Automated protocol tests alone do not establish working multiplayer.
